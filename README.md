# CSS3344 Lab 02 - UI Fundamentals and Layout

Flutter project extending the Lab 01 student profile with reusable layout widgets, portrait/landscape adaptation, and Material/Cupertino date and role pickers.

## Run

```powershell
flutter pub get
flutter run
```
